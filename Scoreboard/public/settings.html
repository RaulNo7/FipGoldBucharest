Open the category on padeltour.ro (tab Înscriși), press Ctrl+A then Ctrl+C, and paste below. One category at a time.

The players are read the way a browser shows them: the site loads its list after the page opens, so the app opens each category in a hidden Microsoft Edge (about 2 seconds per category). Country codes are the 2-letter codes of the flags on the site (RO, MD, ES…). Every import asks whether to keep the current teams and add the new pairs, or replace them. The teams are stored in roster.json in the app's data folder.

Commercial break settings

In OBS: enable Tools → WebSocket Server Settings, and create the commercials scene containing one Media Source (any video file — the app loads the spots into it one by one) with "Restart playback when source becomes active" ticked. For replays: enable the Replay Buffer in OBS (Settings → Output → Recording) and create the replay scene with one Media Source of the name above; the app starts the buffer, sets its length and moves each saved clip into the replay folder. The connection result shows right under the buttons (and in the Broadcast card of the Media tab).

Court TV display

Full-screen score on a black background — open this on a TV / laptop / tablet on the same Wi-Fi (or use the public Court TV link below from anywhere). It keeps showing the final score while the stream plays commercials.

YouTube live stream

Paste the public link of the live stream (or the channel's /live page). The main page and the Scorebug page pick it up immediately and open it in a new tab. Leave it empty to hide the menu entry.

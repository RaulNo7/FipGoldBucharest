Commercials

Play all commercials (and the automatic break after a match) runs these spots one after another, in this order — no merged file needed. Each button below plays just that spot. Either way: the scorebug hides, OBS switches to the commercials scene, the files are loaded into the media source one by one, and OBS returns to the live scene when the last one ends. After a single spot the score always comes back (they are meant for during the game). After Play all or the automatic break, the score comes back only if it interrupted a live match; after a finished match it stays hidden until the next match starts. The last spot played stays highlighted. Files are listed in obs-settings.json (Commercials folder).

Commercial break settings

In OBS: enable Tools → WebSocket Server Settings, and create the commercials scene containing one Media Source (any video file — the app loads the spots into it one by one) with "Restart playback when source becomes active" ticked. The connection result shows in the Broadcast card above.

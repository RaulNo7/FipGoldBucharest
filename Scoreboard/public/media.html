Replay saves the last seconds of the stream from OBS's replay buffer into … and plays the clip straight away on the replay scene; the dropdown keeps the last 10 clips (newest first) so the best points can be shown again during a pause with Play. The scorebug is hidden for the whole replay (the REPLAY cover takes its place) and comes back, if it was showing, when OBS switches back to the live scene at the end of the clip. The clip length and the folder are set in the settings card below.

Commercials

Play all commercials (and the automatic break after a match) runs the spots listed in obs-settings.json one after another — no merged file needed. The dropdown holds every video file in the commercials folder …; Play puts just that file on the stream. Either way: the scorebug hides, OBS switches to the commercials scene, the file is loaded into the media source, and OBS returns to the live scene when it ends. After a single video the score always comes back (they are meant for during the game). After Play all or the automatic break, the score comes back only if it interrupted a live match; after a finished match it stays hidden until the next match starts.

Commercial break settings

In OBS: enable Tools → WebSocket Server Settings, and create the commercials scene containing one Media Source (any video file — the app loads the spots into it one by one) with "Restart playback when source becomes active" ticked. For replays: enable the Replay Buffer in OBS (Settings → Output → Recording) and create the replay scene with one Media Source of the name above; the app starts the buffer, sets its length and moves each saved clip into the replay folder. The connection result shows in the Broadcast card above.
